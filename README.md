# ATM Simulator 🏧

A simple command-line ATM Simulator built using Python that allows users to check their balance, withdraw money, and deposit funds securely using a PIN.

## Features
- **PIN Authentication:** Verifies the user's PIN before granting access.
- **Check Balance:** Displays the current account balance.
- **Withdraw Money:** Checks for sufficient funds and deducts the withdrawn amount.
- **Deposit Money:** Adds the deposited amount to the current balance.
- **Interactive Menu:** Runs continuously until the user chooses to exit.

## How to Run
1. Make sure Python is installed on your system.
2. Run the file using:
   ```bash
   python atm_simulator.py
   ```
3. Enter the default PIN (`1234`) to access the ATM menu.
